# Supply-Chain-Logistics-Analytics---using-TABLEAU
Supply Chain & Logistics Data Analysis Using Tableau

Project By: Sana Mariya

1. Project Overview

This project focuses on analyzing supply chain and logistics data using Tableau. The main objective is to understand product performance, manufacturing costs, shipping operations, inventory levels, and delivery efficiency through interactive data visualizations.

2. Tools Used

- Tableau – Data visualization and analysis
- Excel – Dataset preparation and exploration

3. Dataset Information

The dataset contains supply chain and logistics information, including:

- Product Type
- SKU
- Supplier Name
- Location
- Route
- Shipping Carrier
- Transportation Mode
- Availability
- Cost
- Defect Rates
- Lead Time
- Manufacturing Cost
- Manufacturing Lead Time
- Number of Products Sold
- Order Quantities
- Price
- Revenue Generated
- Shipping Costs
- Shipping Time
- Stock Levels
- Inspection Results
- Customer Demographics

4. Visualizations Created

1. Bar Chart

Used to compare and analyze categorical data and identify differences across product categories.

2. Pie Chart

Used to understand the distribution and contribution of different categories.

3. Line Chart

Used to analyze trends and patterns in supply chain data.

4. Scatter Plot

Analysis: Manufacturing Lead Time vs Manufacturing Cost

- Columns: Manufacturing Lead Time
- Rows: Manufacturing Cost
- Marks: Circle
- Detail: Product Type
- Color: Product Type

Purpose:
To identify the relationship between manufacturing time and manufacturing cost across different product types.

5. Project Objectives

- Analyze supply chain performance.
- Understand manufacturing costs.
- Compare manufacturing lead times.
- Study product category performance.
- Explore shipping and transportation efficiency.
- Understand inventory and stock levels.
- Identify patterns and relationships in the dataset.
